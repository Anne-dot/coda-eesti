# Research Materials

This folder contains research materials gathered during the initial project planning phase.

## Contents

### Lighthouse Performance Tests

**Folder:** [`lighthouse-tests/`](./lighthouse-tests/)

Performance and accessibility test results from various CoDA national websites. Tests were run using Google Lighthouse to compare existing CoDA websites and inform our technical decisions.

### Analysis Script

**[`parse_all_lighthouse.py`](./parse_all_lighthouse.py)**
- Analyzes desktop and mobile Lighthouse test results
- Shows performance, accessibility, best practices, and SEO scores side by side
- Top performers and areas for improvement
- Usage: `python3 parse_all_lighthouse.py`
