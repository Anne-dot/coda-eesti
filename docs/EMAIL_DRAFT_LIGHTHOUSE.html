What is Lighthouse?

Lighthouse is Google's free website testing tool. It measures how fast and accessible websites are for visitors. Think of it like a health check for websites - it shows what's working well and what needs attention.

The test gives scores from 0-100 in different categories:

  • 90-100 (Green) = Excellent
  • 50-89 (Orange) = Needs improvement
  • 0-49 (Red) = Critical issues

I ran tests on both mobile phones and desktop computers to see how coda.org performs.

Test Results - Critical Issues Found

I tested coda.org on November 4, 2025. Both mobile and desktop tests show critical performance problems:

Mobile Performance: 3/100 (RED - Critical)
Desktop Performance: 33/100 (RED - Critical)

Both scores are in the critical "red" zone. For comparison, modern websites typically aim for scores above 90 (green).

What This Means for Users

When a website has a performance score this low, it means:

  • The page takes too long to load or doesn't load at all
  • Users see a blank screen or partially loaded page
  • Mobile users are especially affected
  • People with slower internet connections cannot access the site

Real-world impact: I personally experienced this at our CoDA meeting place (in a basement with limited connectivity). Facebook Messenger worked fine, but coda.org wouldn't fully load - it only displayed the menu, and the page with images below couldn't load at all.

This means people seeking help or looking for meetings may not be able to access CoDA.org at all.

Simple Fixes That Make a Big Difference

The good news: Most of these problems can be fixed by installing free WordPress plugins. You don't need to know how to code - just follow these steps:

1. FIX IMAGES (Saves 1,368 KiB + makes images load only when needed)

Plugin: "EWWW Image Optimizer" (FREE - no limitations)

What it does:

  • Makes your images smaller without looking worse (like zipping a file)
  • Converts images to a newer format (WebP) that loads faster
  • Only loads images when visitors scroll down to see them (instead of loading everything at once)
  • Can optimize all your existing images in bulk

How to install:

  • Go to WordPress dashboard → Plugins → Add New
  • Search "EWWW Image Optimizer"
  • Click "Install" then "Activate"
  • Go to Settings → EWWW Image Optimizer
  • Click "Enable Ludicrous Mode" for best results
  • Click "Scan and Optimize" to fix existing images

Impact: This alone will improve mobile from 3 to around 30-40.

2. SPEED UP CODE LOADING (Saves 3.8 seconds on mobile!)

Plugin: "Autoptimize" (FREE)

What it does:

  • Combines many small files into fewer bigger files (like packing a suitcase efficiently)
  • Removes extra spaces and comments from code (makes files smaller)
  • Lets the page show content before loading all the fancy features

How to install:

  • WordPress dashboard → Plugins → Add New
  • Search "Autoptimize"
  • Install and activate
  • Go to Settings → Autoptimize
  • Check these boxes: "Optimize JavaScript" and "Optimize CSS"
  • Click "Save"

Impact: Removes the 3.8 second delay - page starts showing much faster.

3. SAVE FINISHED PAGES (Makes repeat visits 5-10x faster)

Plugin: "WP Super Cache" (FREE)

What it does:
Think of it like meal prep - instead of cooking from scratch every time someone visits, you save ready-made versions of your pages.

How to install:

  • WordPress dashboard → Plugins → Add New
  • Search "WP Super Cache"
  • Install and activate
  • Go to Settings → WP Super Cache
  • Click "Caching On"
  • Click "Update Status"

Impact: Makes the site much faster for everyone who visits.
